# Prem Prediction
This project builds a sequence-based machine learning model to estimate Premier League title-winning probabilities throughout a season. 
The model leverages LSTM neural networks, padding + masking, and probability normalization to generate realistic, week-by-week league win probabilities for each team.
Currently, the model makes use of limited data set due to cost restraints from API, but plans to add previous seasons are on the way.
